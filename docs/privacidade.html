Política de Privacidade

Conversor de Coleção MTG · atualizada em 7 de outubro de 2026

Resumo

O Conversor de Coleção MTG transforma arquivos de coleção de Magic: The Gathering entre formatos (LigaMagic, ManaBox, Moxfield, Scryfall e outros). A conversão acontece no seu navegador. Este site não tem servidor próprio, não cria contas e não guarda os seus arquivos.

Arquivos que você converte

O arquivo escolhido (do computador, do Google Drive ou colado no campo de texto) é lido e convertido dentro do seu navegador. Ele não é enviado para nós nem guardado em lugar nenhum. Quando você fecha ou recarrega a página, o conteúdo é descartado.

Consultas ao Scryfall

Para identificar as cartas, o site consulta a API pública do Scryfall enviando apenas dados das cartas (nome, edição, número de colecionador ou ID do Scryfall). Nenhum dado pessoal é enviado. O uso do Scryfall segue a política de privacidade do Scryfall.

Google Drive

Se você usar o botão do Google Drive, o Google pede a sua autorização para que o site acesse somente os arquivos que você escolher (permissão drive.file). Com essa permissão o site:

  • baixa apenas o arquivo selecionado, para convertê-lo no seu navegador;
  • não lista, não altera, não apaga e não cria arquivos no seu Drive;
  • não guarda o arquivo nem o token de acesso: eles ficam só na memória da página e somem ao fechá-la;
  • não compartilha nenhum dado do Google com terceiros.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Você pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.

Cookies e rastreamento

O site não usa cookies próprios nem ferramentas de análise ou rastreamento. Se isso mudar (por exemplo, com a inclusão de anúncios), esta página será atualizada antes.

Hospedagem

O site é hospedado no GitHub Pages. Como qualquer servidor web, o GitHub pode registrar dados técnicos de acesso, como endereço IP, conforme a declaração de privacidade do GitHub.

Contato

Dúvidas sobre esta política podem ser enviadas pelo GitHub do projeto.
