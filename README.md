# Conversor de Coleção MTG

Converta sua coleção de Magic entre LigaMagic, ManaBox, Moxfield, Scryfall e outros apps, direto no navegador. Grátis e sem cadastro.

**👉 [hideonchimes.github.io/Scryfall_to_Liga](https://hideonchimes.github.io/Scryfall_to_Liga/)**

## Formatos

| Importa de | Exporta para |
| --- | --- |
| ManaBox, Scryfall, Moxfield, Deckbox, Dragon Shield, TCGplayer, LigaMagic, lista de texto | LigaMagic, ManaBox, Moxfield, Scryfall, lista de texto |

## Recursos

- Detecta o formato do arquivo sozinho.
- Converte vários arquivos de uma vez e baixa tudo em `.zip`.
- Abre arquivos do PC (ou arrastando) e do Google Drive.
- Mostra uma prévia editável antes de baixar: dá para corrigir células, apagar ou adicionar linhas.
- Marca com `VERIFICAR` as cartas que não deu para identificar com certeza.
- Site em português, inglês e espanhol.

## Privacidade

A conversão roda inteira no seu navegador. O arquivo nunca é enviado para um servidor; o site só consulta a API pública do Scryfall para identificar as cartas. Veja a [política de privacidade](https://hideonchimes.github.io/Scryfall_to_Liga/privacidade.html).
